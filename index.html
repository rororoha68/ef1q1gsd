적용 방법

아이폰
  1. 이미지: 저장 후 설정 → 배경화면 → 새 배경화면 추가 → 사진에서 선택
  2. 움직이는 배경(잠금화면 전용, iOS 17 이상): MP4를 Live Photo 변환 앱(IntoLive 등)으로 변환
  3. 설정 → 배경화면 → 새 배경화면 추가 → 사진 → Live Photo 에서 선택해 잠금화면에 지정
  4. 파일 앱에 저장됐다면 공유 버튼에서 이미지/비디오 저장을 눌러 사진 앱으로 옮겨주세요
안드로이드
  1. 이미지: 저장 후 갤러리에서 열어 배경화면으로 설정
  2. 영상: 삼성 등 일부 기종은 설정 → 배경화면에서 갤러리 동영상을 잠금화면으로 지정할 수 있어요 (기종마다 메뉴가 달라요)
  3. 지원하지 않는 기종은 동영상 배경화면 앱을 이용하거나 이미지를 사용해주세요
PC
  1. 이미지: 우클릭 → 바탕 화면으로 설정 (맥은 시스템 설정 → 배경화면)
  2. 영상: Lively Wallpaper(무료) 같은 앱에 MP4를 지정해주세요
